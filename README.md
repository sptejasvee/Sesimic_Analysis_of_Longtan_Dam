# Sesimic_Analysis_of_Longtan_Dam

1. A 3D finite element model of Longtan Dam in Abaqus/CAE using the Concrete Damaged Plasticity (CDP) model, comprising 734 elements and 815 nodes to simulate nonlinear concrete behavior.
2. Modal analysis to calculate the first 20 natural frequencies (0-10 Hz) and resonance conditions against an excitation frequency of 1.39 Hz.
